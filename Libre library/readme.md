# Libre library
The libre library app is made to provide user with data how many and how much time there is left to finish all libre links scanners (for diabities)
It also stores their serial number for reports to the libre company:
## Goals
- Provide users with an easy way to track their Libre link scanners.
- Store serial numbers for reporting purposes.
- calculate the remaining time for each scanner based on usage.
- Collect data directly from the Libre link scanners (with nfc reading not sure how much data i can get. focusing on serial number).
